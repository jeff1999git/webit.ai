# Webitai Labs website

Marketing website for **Webitai Labs**, an IT services and software development company.
It presents our services and real projects and turns visitors into project enquiries
through a contact form that emails each enquiry to our inbox.

Live: <https://webitai.vercel.app>

## Stack

- [Next.js 15](https://nextjs.org) (App Router, mostly static pages) with React 19 and TypeScript
- Tailwind CSS 3 for styling, Geist Sans / Geist Mono fonts
- framer-motion for animations
- [Resend](https://resend.com) for enquiry email delivery
- sharp (dev only) for the image and icon scripts
- Hosted on [Vercel](https://vercel.com)

## Getting started

Requires Node.js 20 or later.

```bash
npm install
cp .env.example .env.local   # then fill in RESEND_API_KEY
npm run dev
```

Open <http://localhost:3000>. The site runs without any environment variables; only the
enquiry form needs `RESEND_API_KEY` to actually send email.

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Production build |
| `npm run start` | Serve the production build |
| `npm run lint` | ESLint (Next.js config) over `app`, `components`, `lib` and `content` |
| `npm run optimize` | Generate AVIF / WebP / compressed fallbacks of the PNG and JPG files in `public/` into `public/optimized/` (`optimize:clean` empties that folder first) |
| `npm run icons` | Regenerate `app/icon.png` and `app/apple-icon.png` from `public/webitai-logo.png` |

## Environment variables

Copy `.env.example` to `.env.local` for local work and set the same names in Vercel
(Project → Settings → Environment Variables).

| Name | Required | Purpose |
|---|---|---|
| `RESEND_API_KEY` | Yes, for enquiries | Resend API key used by `/api/contact`. Without it the form shows a friendly "please email us instead" error. |
| `CONTACT_TO_EMAIL` | No | Inbox that receives enquiries. Defaults to the fallback address in `app/api/contact/route.ts`. |
| `CONTACT_FROM_EMAIL` | No | Sender, e.g. `Webitai Labs <hello@yourdomain.com>`. Must be on a domain verified in Resend. Defaults to `Webitai Labs <onboarding@resend.dev>`. |
| `NEXT_PUBLIC_SITE_URL` | No | Public base URL for canonical links, the sitemap, robots.txt and social previews. Defaults to `https://webitai.vercel.app`. |

## Editing content

Almost all text lives in `content/` and `lib/enquiry.ts`, so most updates don't touch
any components. Only publish things that are true: no invented clients, numbers or
testimonials.

### `content/site.ts`

Brand name, tagline, description, navigation, the header call-to-action and contact
details. Contact fields set to `null` (and an empty `socials` list) are hidden
everywhere on the site, so leave them empty rather than adding placeholders.

Still to fill in:

- `contact.phone` — business phone in international format
- `contact.whatsapp` — WhatsApp number as digits with country code (used for the click-to-chat link)
- `contact.location` — city / region to display
- `socials` — e.g. `{ label: "LinkedIn", href: "https://…" }`

### `content/services.ts`

The seven services shown on the home page, `/services`, in the footer and in the
enquiry form's service list. Each has a `slug` (also its anchor on `/services`), an
`icon` (one of the names in `components/ui/Icon.tsx`), a summary, an intro and the
*What's included* / *Good for* / *What you get* lists.

### `content/projects.ts`

The portfolio. To add a project, append an object to the `projects` array (projects
appear in array order) with:

- `slug` — URL part for `/projects/<slug>`
- `title`, `client` (or `null` with a `clientDescription` when the client shouldn't be named)
- `categories` — keys of `projectCategories`; the filter on `/projects` only shows categories that have projects
- `status` — `"live"` or `"prototype"`
- `summary` (cards), `overview`, `features`, `stack`
- `links` — external links, with an optional `note` such as "Login required"
- `relatedService` — a service slug; used to prefill the enquiry form from the project page
- `cover.gradient` — Tailwind gradient stops for the card cover

To show a screenshot instead of the gradient cover, put the image in `public/projects/`
and set `cover.image`, e.g. `{ src: "/projects/my-project.webp", alt: "Home page of …" }`.
The cover is cropped from the top, so a wide screenshot works best.

The sitemap and the project pages pick up new projects automatically.

### `content/company.ts`

The trust pillars, the "why choose us" points and the four process steps. Keep these
as statements about how we work, not claims about results.

### `lib/enquiry.ts`

Field rules shared by the form and the API. `budgetOptions` holds the budget ranges
offered in the form (INR, still to be confirmed); the service list is built from
`content/services.ts`.

## Enquiry form and email delivery

`/contact` posts to `/api/contact`, which validates the input with the same rules as the
form, silently drops submissions that fill the hidden spam-trap field, applies a small
in-memory rate limit per IP address, and sends the enquiry as a plain-text email through
Resend with the enquirer's address as reply-to.

- Until a domain is verified, Resend's shared sender `onboarding@resend.dev` only
  delivers to the email address of the Resend account owner, so `CONTACT_TO_EMAIL` must
  be that address.
- To send from your own address (and to any inbox), verify a domain in Resend
  (Domains → Add domain, then add the DNS records it lists) and set
  `CONTACT_FROM_EMAIL` to an address on that domain.
- The rate limit lives in server memory, so on serverless hosting it is best effort
  only.

## SEO

- Site-wide metadata (title template, description, Open Graph and Twitter defaults) in
  `app/layout.tsx`; each page sets its own title, description and canonical URL.
- `app/sitemap.ts` → `/sitemap.xml` (all pages and every project)
- `app/robots.ts` → `/robots.txt` (everything allowed except `/api/`)
- `app/opengraph-image.tsx` → default 1200×630 share image
- `app/icon.png`, `app/apple-icon.png` → favicon and Apple touch icon

All absolute URLs come from `NEXT_PUBLIC_SITE_URL`, so set it when moving to a custom
domain.

## Deployment

The site deploys to Vercel from the Git repository; no build settings need changing
from the Next.js defaults.

1. Import the repository in Vercel (framework preset: Next.js).
2. Add the environment variables above (at least `RESEND_API_KEY`).
3. When you add a custom domain, set `NEXT_PUBLIC_SITE_URL` to it and redeploy so the
   canonical links, sitemap and share images use the new address.
